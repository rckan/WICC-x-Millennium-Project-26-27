# CLAUDE.md

Research repo for a WICC x Millennium student project: **The Impact of Agentic AI on Service-Based Industries**. Output is a spring presentation, not software.

## Guidance for AI assistants

- The proposal is in `docs/proposal.md` and the research questions are in `docs/research-questions.md`. Stay inside that scope.
- **Never invent statistics, quotes, or citations.** Every claim needs a source ID from `research/sources.md`. If you can't verify something, mark it `TODO: verify`.
- When adding a source, add it to `research/sources.md` first, then reference it by ID.
- Use the templates (`research/notes/_template.md`, `case-studies/_template.md`) for new files.
- Keep the five themes in `research/themes/` aligned with the key areas in the proposal.
- Python analysis lives in `analysis/`. Dependencies are in `analysis/requirements.txt`.
